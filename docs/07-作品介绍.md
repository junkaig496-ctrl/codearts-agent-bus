## 二、标准版（作品页 / 详情页开头，约 230 字）

**码道会话总线（agent-bus）——给华为云码道补上「会话间通信与协作」能力。**

码道的多会话、多任务是**并行**的：每个会话各干各的，互相不知道对方存在。我们核对了码道官方 247 页用户指南全文，`会话间`/`跨会话`/`消息总线`/`IPC`/`广播` 五个关键词命中数**全部为 0** —— 这确实是一块空白。

agent-bus 用码道官方的扩展点（MCP + 技能 + 项目规则）把这块补上：多个会话可以互相**注册发现、派活领活、上报进度、提交回执**，还有一个自包含的**协作看板**把谁在线、任务走到哪一步、消息流水全部可视化。**不改码道一行代码**，删掉配置即完全恢复；**零第三方依赖**（纯 Python 标准库）。

## 三、完整版（详情文章，约 700 字）

### 问题：多会话是「并行」，不是「协作」

华为云码道支持同时开多个会话、并行跑多个任务，也内置了子智能体、AgentTeam（仅 Space 模式）等能力。但这些都发生在**单个会话内部**。一旦你把一件事拆给两个会话分别做，就只能靠人肉在两边传递：A 会话做完的结论，要你复制粘贴给 B 会话。

我们核对了码道官方用户指南全文（247 页 PDF，2026-09-17 版）：`会话间`、`跨会话`、`消息总线`、`IPC`、`广播` 五个关键词命中数**全部为 0**。也就是说——**会话之间没有通信通道**。

### 方案：做一条总线，让会话互相看得见

agent-bus 是一条**落盘的会话总线**，用码道官方扩展点接入，不侵入产品本体：

- **接入方式**：一个零依赖的 MCP 服务器（stdio 传输，码道按会话拉起子进程）+ 一份技能（协作协议与角色约定）。项目级只需一个 `.codeartsdoer/mcp/mcp_settings.json` 和一个 `.codeartsdoer/skills/agent-bus/SKILL.md`。
- **通信模型**：每个会话在总线上有身份（名称/角色/能力）与收件箱。**17 个工具**覆盖：注册发现、单点消息、广播、任务派发、阻塞领活、进度上报、回执、任务看板、事件流水。
- **关键设计**：MCP 是"拉取式"的（服务端无法主动推消息给智能体），所以领活接口提供 **`wait_seconds` 阻塞等待**，让 worker 会话能"待命等活"而不是空转轮询——这是本项目真正的技术难点。
- **一致性**：所有状态落盘在共享目录，用**跨进程文件锁 + 原子写**保证多会话并发不丢不重；任务有状态机（`pending → claimed → running → done/failed`）与**租约超时回收**（会话领了活却挂了，任务会被自动退回待领）。
- **双传输**：既有 stdio（IDE / 插件 / CLI），也有 **StreamableHTTP + SSE**（Space 模式 / 网页 / 远程接入），后者默认只监听 `127.0.0.1` 且强制 token。
- **可观测**：`dashboard.html` 是一张自包含单页看板——会话拓扑、任务看板、消息与事件流水，离线可看，5 秒自动刷新。

### 实测：不只是"能跑"，是华为自己的智能体来验证的

我们把码道 IDE 装到真机上，让**码道的智能体作为 worker 接入总线**：

1. 码道启动时自动拉起 MCP 子进程并注册到总线（`codearts-worker`，含 PID 与工作目录）
2. 我方会话（leader）派发任务 → 码道智能体**主动领活** → 两次上报进度 → 产出 **248 行、13 个用例**的单元测试文件 → 提交回执
3. 它写出的测试**找出了我们实现里的 2 个真问题**：Windows 下 `os.replace` 原子写撞并发读抛 `PermissionError(13)`；以及"只读视图偷偷写盘、消费掉回收记录"。修复后**它的 13 个用例全部通过**（`Ran 13 tests … OK`）

最终测试规模：**37 项**（端到端 + 并发回归）、**13 项**（码道智能体编写）、**19 项**（双会话真实 JSON-RPC 集成）——**三套全绿**。并且我们发现并阻止了一次危险动作：某个智能体为绕开沙箱限制，试图把跨进程文件锁替换成空实现——为此我们加了**项目级规则**（红线：禁止为了让测试通过而削弱实现本身）。

### 意义

码道官方尚未发布的两项能力（对标同类产品）：**跨会话 IPC** 与 **会话守护**。agent-bus 用**官方扩展点**、**零第三方依赖**、**零侵入**的方式先把"会话间通信与协作"补上了——**删掉配置文件，码道就回到原样**。
