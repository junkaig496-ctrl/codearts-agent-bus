## 二、卡点：**只有你本人能做的两步**（涉及凭据，我不代持）

### ① 华为云 AK/SK（Step 1 必需）

官方技能明确：**永久 AK/SK 仅存本地环境变量，不上传、不落盘明文**。
请你在自己的终端里设置（我这边的会话不写入、不读取这两个值）：

```powershell
setx HUAWEICLOUD_SDK_AK "<你的 AK>"
setx HUAWEICLOUD_SDK_SK "<你的 SK>"
```

或者用 KooCLI 交互式配置（会提示输入，同样不经过我）：

```powershell
hcloud configure
```

设置完成后告诉我，我接着跑 Step 1（`resolve-domain.mjs` → `gen_sts.py`，生成 900 秒最小权限 STS）。

### ② 代码必须有一个**公开 Git 仓库地址 + 分支**（Step 3 必需）

官方页说明：作品中心支持 **GitHub / GitCode / Gitee** 公开仓；发布必须提供仓库地址和分支。
当前仓库只有本地提交，还没有远程。两条路选一条：

* **GitCode（官方推荐路径）**：官方凭据工具 `gitcode-oauth` 需先手动安装（自动安装在本机失败：
  `gitcode-oauth 二进制缺失且自动安装失败（网络/架构不支持）`）。装好后可跑
  `node <skill>/scripts/gitcode-oauth.ensure.mjs --start`，它会打印一条登录链接/二维码，
  你在任意浏览器授权即可（**脚本自带回调服务器，不需要我开浏览器**）；再 `--wait <session_id>` 拿 token。
* **GitHub**：把本仓库推到你自己的 GitHub 账号（`junkaig496-ctrl`）后，把 `仓库地址` 与 `分支名` 告诉我即可。
  推送需要你的凭据，我不代做。

### ③ 活动选择（Step 7）——等 ①② 完成后续到

STS 就绪后即可拉取可投稿活动列表：

```bash
node <skill>/scripts/api.mjs GET "/v1/gallery/camps" --creds-file <sts json> \
  --fields "id,name,school,status,startsAt,endsAt"
```

**必须在列表里选「HCSD校园大使圈层激励活动（桂电）」**（只有状态为"可投稿"的活动才能选；
若列表里没有它，说明报名/关联还没生效，需要先在活动页报名）。选错活动等于白做。

### ④ 最后一步「提交」由你点

Step 8 `publish-work.mjs` 会先跑 `check-gates.mjs` 门禁检查（作品名、封面、介绍、详情包、
Git 仓库、活动）。**门禁全绿之后我把状态交给你，由你确认并点击提交。**
